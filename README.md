> ## 프로젝트 개요
- 게임명 : Meowment
- 장르 : 액션 퍼즐 어드벤처
- 엔진 : 언리얼 5.0
- 주제 : “이별을 통한 성장과 재회”
소중한 존재와 이별한다는 것은 슬픔만을 남기는 것이 아닌 그 이별을 받아들이며 성장할 수 있음을 이야기한다.
고양이의 목숨이 9개라는 전설을 통해, 새로운 시작과 재회의 가능성을 암시한다.
- 시놉시스 : 고양이 네로를 그리워하던 소녀 올리브는 슬픔에 잠긴 나날을 보내던 중에 인터넷에서 죽은 영혼을 되살리는 강령술을 발견한다.
  사랑하는 네로를 다시 만나고 싶은 마음에 저승으로 향한 올리브는 위험천만한 여정을 시작하게 된다. 저승에서 네로와 재회하지만, 올리브는 진정한 이별을 받아들이며 성장하게 되며 현실로 돌아온다.
  그러나 길거리에서 마주친 한 고양이의 눈빛에서 네로의 흔적을 발견하며 이야기는 끝난다.
